# LLM Self-Analysis

## Evidently AI LLM Evaluation

- Guides on automating LLM self-evaluation for output quality, relevance, and scaling assessments like accuracy or bias checks.

## Nexla LLM Comparison

- User guide comparing LLMs on features such as use case compatibility, effectiveness (relevance, faithfulness), deployment options, and top models for tasks like conversational AI.

## NVIDIA NeMo Guardrails

- Details supported LLM providers (e.g., OpenAI, Anthropic) and how to configure for features like self-hosted or cloud deployment.

## Reddit Self-Evaluation Prompt

- Practical user steps for prompting LLMs to self-assess responses on accuracy, clarity, and refinement.

## iTernal AI LLM Selection

- Benchmarks 30+ LLMs (e.g., GPT-4o, Claude 4) on features like context windows, pricing, and use-case support.

## Reddit System Self-Analysis

- Template for LLMs to report capabilities (e.g., text generation, modalities), languages, limitations, and safety features.

## Med LLM AutoEval GitHub

- GitHub repo for automated LLM evaluation using Colab notebooks, supporting benchmarks like AGIEval, TruthfulQA, and Bigbench for quick performance assessment.

## Langfuse GitHub

- Open-source LLM engineering platform on GitHub for monitoring, evaluating, and debugging AI apps with LLM-as-a-judge and custom pipelines.

## DeepEval Framework

- Open-source framework for LLM evaluation with 14+ metrics like summarization and hallucination, integrated with Pytest for unit testing.

## RAGAs Framework

- GitHub-based tool focused on RAG pipelines, evaluating faithfulness, contextual precision, and other self-assessment metrics.

## Awesome LLM Services GitHub

- Curated list of 117+ self-hostable LLM services and tools on GitHub, including evaluation infrastructure for local AI deployment.
