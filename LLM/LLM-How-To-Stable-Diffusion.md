# Stable Diffusion

Stable Diffusion is a family of open-source AI image generation models that create images from text prompts.

It is one of the most popular alternatives to proprietary image generators because it can be run locally and customized.

## Key Features

### Text-to-Image

- Generate images from written descriptions

### Image-to-Image

- Transform an existing image while preserving its overall structure

### Inpainting

- Add, remove, or replace parts of an image

### Outpainting

- Extend an image beyond its original borders

### Fine-Tuning

- Train the model on specific art styles, characters, or subjects using techniques such as LoRA

## Popular Versions

### Stable Diffusion 1.5

- Fast
- Widely supported by community tools

### Stable Diffusion XL (SDXL)

- Produces higher quality and more detailed images than earlier versions

### Stable Diffusion 3

- Improved prompt understanding
- Better text rendering
- Newer generation of the model family

## Common User Interfaces

### AUTOMATIC1111 WebUI

- Feature rich
- Highly customizable

### ComfyUI

- Node based workflow interface
- Designed for advanced users

### Fooocus

- Beginner friendly
- Simplified controls

## Typical Hardware Requirements

### GPU

- NVIDIA GPU with at least 8 GB of VRAM recommended
- More VRAM allows larger images and faster generation

### RAM

- 16 GB or more recommended

### CPU

- Can run on CPU only
- Image generation is significantly slower than with a supported GPU
