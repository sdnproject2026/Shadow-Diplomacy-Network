# LLM Features

## Gemini

- Strengths: Integrated ecosystem with Google Search, YouTube, and Docs; strong multimodal reasoning and image interpretation.  

- Paid vs Free Features: Free for standard use; advanced Gemini 1.5 Pro access requires a Google One AI Premium subscription.  

- Registration: Requires Google account login.  

- Android App: Yes, integrated in the Google app and as standalone Gemini app.  

- Privacy: Governed by Google’s privacy policy; conversations may be stored or reviewed for service improvement.  

- Supports Tor Orbot VPN: Limited access due to Google network restrictions.  

## Perplexity

- Strengths: Real-time search integration, concise factual summaries, and transparent citations.  

- Paid vs Free Features: Free core model; Perplexity Pro adds GPT-4-Turbo access, file upload, and enhanced privacy options.  

- Registration: Optional for free tier; required for Pro subscription.  

- Android App: Yes, available on Google Play.  

- Privacy: Minimal data collection, strong transparency about source use; can use in anonymous mode.  

- Supports Tor Orbot VPN: Generally works, some connection lag may occur.  

## ChatGPT

- Strengths: Advanced reasoning with large context windows, code and text generation, and creative writing abilities.  

- Paid vs Free Features: Free access to GPT-3.5; GPT-4 available with ChatGPT Plus.  

- Registration: Required via OpenAI account (email, Google, or Microsoft).  

- Android App: Yes, official app on Play Store.  

- Privacy: Conversations may be used to improve the model unless sharing is turned off.  

- Supports Tor Orbot VPN: Partially functional, may need manual proxy configuration.  

## Copilot

- Strengths: Deep Microsoft 365 and Windows integration; excels at productivity, summarizing, and document automation.  

- Paid vs Free Features: Free basic answers; premium includes integration with Office and enterprise tools.  

- Registration: Requires Microsoft account.  

- Android App: Integrated in Microsoft Edge, Outlook, and Copilot app.  

- Privacy: Uses enterprise-grade Azure data compliance; user data protected under Microsoft privacy terms.  

- Supports Tor Orbot VPN: Limited connectivity through Microsoft network.  

## Duck

- Strengths: Privacy-first conversational AI from DuckDuckGo using anonymized LLM calls.  

- Paid vs Free Features: Currently free; no paid options.  

- Registration: No registration required.  

- Android App: Works through DuckDuckGo mobile browser or app.  

- Privacy: Strong user anonymity, no saved chat logs, queries routed through DuckDuckGo’s secure proxy.  

- Supports Tor Orbot VPN: Fully compatible with Tor network.  

## Claude

- Strengths: Strong comprehension and safe, context-aware responses; handles long documents effectively.  

- Paid vs Free Features: Free tier offers Claude Instant; paid Pro version gives access to Opus and Sonnet.  

- Registration: Required with email; integrates with Slack and Notion.  

- Android App: No dedicated app, but web mobile compatible.  

- Privacy: Minimal data logging, no training on user conversations.  

- Supports Tor Orbot VPN: Compatible but slower through Tor.  

## Lumo

- Strengths: Secure, privacy-focused AI integrated with ProtonMail ecosystem.  

- Paid vs Free Features: Free guest mode; enhanced tools for Proton subscribers.  

- Registration: Optional guest access; Proton account recommended for full features.  

- Android App: Accessible through Proton app suite.  

- Privacy: High privacy with end-to-end encryption; based in Switzerland under GDPR protection.  

- Supports Tor Orbot VPN: Fully functional.  

## Pi

- Strengths: Emotionally intelligent AI designed for empathetic conversations and guidance.  

- Paid vs Free Features: Currently free; premium personal features planned.  

- Registration: Required for cross-device sync.  

- Android App: Yes, available officially.  

- Privacy: Protects chat data from third-party sharing; transparent analytics policy.  

- Supports Tor Orbot VPN: Works with reduced performance.  

## Poe

- Strengths: Acts as a hub for multiple AI models including GPT, Claude, and Gemini variants.  

- Paid vs Free Features: Free with limits; Pro unlocks faster and broader access to premium models.  

- Registration: Required (email or social media login).  

- Android App: Yes, widely available.  

- Privacy: Conversations stored for account sync; user control over deletion.  

- Supports Tor Orbot VPN: Access may be throttled.  

## Tidio

- Strengths: Conversational AI for customer service, lead generation, and e-commerce automation.  

- Paid vs Free Features: Free chatbot plan with restrictions; advanced analytics in paid tiers.  

- Registration: Required with email.  

- Android App: Yes.  

- Privacy: Follows EU GDPR; anonymized visitor data for insights.  

- Supports Tor Orbot VPN: Limited compatibility due to company network filters.  

## Intercom

- Strengths: AI-assisted support and CRM automation for businesses.  

- Paid vs Free Features: Business pricing only; free trial available.  

- Registration: Required with company credentials.  

- Android App: Yes.  

- Privacy: Enterprise-focused with secure data isolation.  

- Supports Tor Orbot VPN: Generally inaccessible over Tor.  

## Drift

- Strengths: Marketing AI assistant for real-time website communication and sales interactions.  

- Paid vs Free Features: Paid-only product with demo trials.  

- Registration: Required for setup.  

- Android App: Yes.  

- Privacy: Complies with enterprise data protection standards.  

- Supports Tor Orbot VPN: Usually blocked due to IP verification filters.  

## Lindy

- Strengths: Personal AI assistant specializing in productivity, scheduling, and workflow automation.  

- Paid vs Free Features: Free beta access; full automation tools behind subscription.  

- Registration: Required.  

- Android App: No official app yet.  

- Privacy: Focus on private task management; minimal external data use.  

- Supports Tor Orbot VPN: Functional in limited form.

# API Support

## Free

### Duck

- Api Methods: Privacy proxy endpoints for natural language queries over https json.

- Paid Vs Free Api Usage: Free privacy focused use with strict rate limits and low volume allowances, aimed at individual users rather than heavy commercial traffic.

- Registration Key Id Requirements: Light key or token for automated calls, often tied to minimal account data to preserve anonymity.

### Lumo

- Api Methods: Assistant style endpoints embedded in the Proton ecosystem for secure email and productivity scenarios.

- Paid Vs Free Api Usage: Guest and Proton user access included at no extra cost for low volume, with no broad open billing based developer tier.

- Registration Key Id Requirements: Proton account for full use, internal tokens handled inside Proton apps, external keys rarely issued.

### Pi

- Api Methods: Assistant dialogue endpoints using https json with session identifiers.

- Paid Vs Free Api Usage: Early stage free use aimed at personal assistance, tight quotas and not yet positioned as a paid high volume api.

- Registration Key Id Requirements: User account registration and issued api key for approved partners.

### Studio

- Api Methods: Beta json api for story and shot based video generation workflows.

- Paid Vs Free Api Usage: Currently free while in limited beta with low caps, not yet charging per clip or minute.

- Registration Key Id Requirements: Account plus beta approval and issued api token.

## Free Limited

### Gemini

- Api Methods: Rest style json endpoints for chat, multimodal prompts, and embeddings in Google Ai Studio or Vertex Ai.

- Paid Vs Free Api Usage: Free tier with limited monthly requests and lower throughput, higher limits and more models via paid Google One Ai Premium or cloud billing.

- Registration Key Id Requirements: Google account, cloud project, and api key or oauth credentials from the cloud console.

### Claude

- Api Methods: Rest json endpoints for messages, streaming chat, tools, and embeddings.

- Paid Vs Free Api Usage: Limited free usage via web, api access metered with small free or trial quotas before paid token billing applies.

- Registration Key Id Requirements: Anthropic account, billing profile, and one or more organization scoped api keys.

### Leonardo

- Api Methods: Https json endpoints for image generation, upscaling, and asset management.

- Paid Vs Free Api Usage: Free tier with small daily or monthly image quota, higher volumes and priority behind paid plans.

- Registration Key Id Requirements: Leonardo account with personal api token from dashboard.

### Canva

- Api Methods: Developer platform apis and sdks for creating designs and invoking Ai features.

- Paid Vs Free Api Usage: Some free integration capacity, but Ai image and advanced tools quickly consume credits and may require Pro or enterprise tiers.

- Registration Key Id Requirements: Canva account, registered app, client id and secret with oauth tokens.

### Ideogram

- Api Methods: Json endpoints for prompt submission and image retrieval.

- Paid Vs Free Api Usage: Small free daily or monthly allowance, larger or commercial usage requires paid credits.

- Registration Key Id Requirements: Ideogram account and api key.

### Recraft

- Api Methods: Web apis for vector and raster asset generation via json.

- Paid Vs Free Api Usage: Free tier with limited generations and exports, paid plans expand image counts and resolutions.

- Registration Key Id Requirements: Recraft account and api key.

### Dreamstudio

- Api Methods: Rest endpoints for text to image generation using Stability models.

- Paid Vs Free Api Usage: Starter free credits for new accounts, continued usage requires purchasing additional credits.

- Registration Key Id Requirements: Dreamstudio or Stability account with api key.

### Freepik

- Api Methods: Http apis for Ai image generation and search within the Freepik platform.

- Paid Vs Free Api Usage: Limited free generation and downloads, higher use and better rights available to premium or enterprise customers.

- Registration Key Id Requirements: Freepik account and token linked to subscription.

### Runway

- Api Methods: Rest and web apis for asynchronous video generation and editing jobs.

- Paid Vs Free Api Usage: Free trial with small quota, continued or heavier usage requires paid credits or plans.

- Registration Key Id Requirements: Runway account and workspace api key.

### Invideo

- Api Methods: Https json endpoints for script to video and media automation.

- Paid Vs Free Api Usage: Minimal free tier support suitable for testing, production volume requires paid plans.

- Registration Key Id Requirements: Invideo account with api key tied to plan.
