# EFTA 53-page gap

The original 53-page gap identified by document reviewers has only been partially resolved

The DOJ subsequently released 16 pages that filled portions of the gap

The remaining 37 pages have not been restored to the public database

DOJ statements have attributed missing records to misfiling, duplicate handling, privilege review, redaction review, or reprocessing efforts

Public reviewers continue to identify unreleased records through Bates numbering, serial logs, discovery indexes, and document sequence analysis

## Bates Numbering

vs EFTA Numbering

### Definition

- Bates numbering is a document-control system used in litigation, investigations, discovery productions, and records management

- Each page receives a unique sequential identifier

- The number identifies the page itself, not necessarily the document

- Consecutive Bates numbers usually indicate pages that were produced together in the same collection

## Purpose

- Track individual pages across large document productions

- Identify missing pages or gaps

- Cite precise pages in court filings

- Preserve page sequence during disclosure

## Example

- 00057716

- 00057717

- 00057718

- 00057719

- 00057720

- Each number represents a separate page

- A 10-page document might occupy Bates numbers 00057716-00057725

## Importance In The 53-Page Gap

- Reviewers observed a jump in page numbering

- Documents before the gap ended at one Bates number

- Documents after the gap resumed at a later Bates number

- The missing sequence suggested pages existed but were not publicly released

- This is how the original 53-page discrepancy was identified

# EFTA Numbering

## Definition

- EFTA numbers were assigned during the Epstein Files Transparency Act publication process

- They function as release-package identifiers rather than simple page numbers

- An EFTA identifier generally refers to a released record or file within the public database

## Example

- EFTA02858481

- EFTA02858491

- EFTA02858495

## Purpose

- Identify records within the DOJ public EFTA repository

- Allow users to locate a specific released item

- Track release status of documents

- Organize files added during multiple publication waves

# Key Difference

## Bates Numbering

- Page-level identifier

- Sequential page tracking

- Usually inherited from litigation or discovery productions

- Useful for finding missing pages

- One page equals one Bates number

## EFTA Numbering

- Release-level identifier

- Repository tracking system

- Created for the public release program

- Useful for locating released records

- One EFTA record may contain multiple Bates-numbered pages

## Related Concepts

### FBI Serial Number

- Identifies a record or item within an FBI case file

- Example: Serial 252

- One serial may contain multiple pages

- One serial may span many Bates numbers

### Sub-Document Number

- Internal grouping within a serial

- Example: 3501.045-004

- Often corresponds to a distinct interview, notes package, attachment, or work paper set
