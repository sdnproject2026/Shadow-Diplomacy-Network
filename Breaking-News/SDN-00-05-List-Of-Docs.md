# List of Docs

Below are third-party, independently operated archives and search platforms that index DOJ/EFTA Epstein document releases and support full-text or metadata search.

## Epstein Document Archive

### Retired

- https://EpsteinInvestigation.org

- ~207,000+ documents indexed

Full-text search across

- DOJ EFTA releases

- FBI Vault materials

- House Oversight documents

- FOIA releases

Provides document-level browsing and keyword search across emails, PDFs, and exhibits

## EpsteinGate

- https://Epsteingate.org

- Multi-million document search layer

Features

- Full-text search across DOJ EFTA corpus

- Co-mention search (entities appearing in same document

- Direct EFTA ID lookup

## Epstein Files Archive

### Retired

- https://epsteinfilesarchive.com

Unified search across

- Estate email dumps

- Court filings

- FOIA releases

- CBP travel data

Includes AI-assisted search over normalized document corpus

## Epstein Files Search Database

- https://epstein-check.org

- ~115,000+ DOJ EFTA documents

- Simple keyword search interface

- Focused on raw document retrieval

## ChatFiles Epstein Archive

- https://chatfiles.org

- ~790,000+ documents indexed

Features

- OCR + full-text search

- Photo extraction and indexing

- Multi-language interface

Includes emails, reports, and scanned exhibits

## Epstein Open Source Archive

- https://epsteinopensource.com

- ~1.3M+ documents indexed

- Community-driven investigation platform

Includes

- entity graphing

- co-mention analysis

- investigative threads

## Epstein Document Archive

- https://epsteinarchive.org

- Curated document browsing interface

- Includes key filings (depositions, black book, lawsuits

Less full-text search focused, more structured browsing

## Epstein Project

- https://epsteinproject.com

- ~1.4M+ documents (multi-batch DOJ ingestion

Advanced

- semantic search

- AI assistant query layer

- investigative dashboards

## Epstein Files / Unredact Mirror

- https://unredact.org

- Large-scale mirrored DOJ dataset (~1.4M files claimed

Emphasis on

- relationship graphing

- agent-style query system

- structured dataset exploration

## Jmail

- https://jmail.world/ 

- email browser interface

- UI layer simulating Gmail inbox browsing of EFTA email dumps

Not a raw repository, but a structured interface over DOJ releases
